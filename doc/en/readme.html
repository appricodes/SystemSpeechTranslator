System Speech Translator for NVDA

The System Speech Translator add-on captures audio from your computer's default speakers, transcribes the speech, translates it into your preferred language using the advanced X.AI API, and outputs the result seamlessly via NVDA.

Configuration

Before using the add-on, you must configure your API key and preferences:

  1. Open the NVDA menu (NVDA+N).
  2. Navigate to Preferences > Settings.
  3. Scroll down to the System Speech Translator category.
  4. XAI API Key: Enter your valid X.AI API key. Use the "Show API Key" checkbox to verify you have pasted it correctly.
  5. Target Language: Select the language you want the audio translated into. If you select "TTS Language", the add-on will automatically detect and match your current NVDA voice language.
  6. Show results in a popup window: If checked, translations will be displayed in an accessible text window for reading. If unchecked, NVDA will instantly speak the translated text.
  7. Enable continuous background recording: If checked, the add-on maintains a rolling memory of the last few seconds of system audio, allowing you to retroactively translate audio that just played.

Keyboard Shortcuts

The add-on uses a single unified gesture to control all translation features:

  • NVDA+Shift+Escape:
    • Single Press: Instantly translates the last X seconds of audio (if retroactive background recording is enabled in settings).
    • Double Press: Starts a new manual audio recording. Pressing the shortcut again (single or double press) will stop the recording and begin translation.

Usage Instructions

1. Retroactive Background Translation

If you miss what was just said in a video or voice chat, press NVDA+Shift+Escape once. The add-on will grab the recent audio from memory (up to the duration specified in your settings), translate it, and read it out to you. You will hear a high-pitched beep indicating the translation process has started.

2. Manual Recording

To translate a longer segment of audio:

  • Double-press NVDA+Shift+Escape.
  • NVDA will announce "Recording started" followed by a beep.
  • Let the audio play. (Note: Recordings are hard-capped at 120 seconds to prevent API timeouts).
  • Press NVDA+Shift+Escape again to stop recording. NVDA will announce "Processing" and fetch your translation.
Note: If a translation result dialog is currently open, triggering a new translation will automatically close the old window and display the new result. You can also press the Escape key to close the translation popup at any time.
