How to obtain a Grok API Key

If you wish to use the Premium Grok engines for transcription or translation, follow these steps:

  1. Create an Account: Go to console.x.ai and sign in using your X (Twitter) account or email.
  2. Add Payment Method: Click on your profile or Billing in the sidebar. You must add a credit card and load a small minimum balance (e.g., $5) to unlock API access.
  3. Create the Key: Navigate to the API Keys section in the dashboard.
  4. Click Create API Key, give it a name like "NVDA Translator", and click Create.
  5. Copy the Key: Copy the newly generated key (it usually starts with xai-...) and paste it into the NVDA System Speech Translator settings!
